# A股短线标准量化交易协议 (DS-A-STOCK-STD-1.0)

## 一、 五大核心死律与一票否决
1. **6选1唯一操作标签**：持仓待涨 / 建仓上车 / 回踩低吸 / 逢高减仓 / 破位止损 / 空仓观望。严禁模糊模棱两可。
2. **大盘三色闸门**：
   - 进攻期（红灯）：仓位上限 80%，顺势突破；
   - 震荡期（黄灯）：仓位上限 40%~50%，箱体低吸高抛；
   - 退潮期（蓝/黑灯）：强制空仓避险，严禁新开仓。
3. **点位有效/失效确认**：建仓区间宽度 <= 3%，必须带明确有效确认点位与失效止损点位。
4. **浮亏绝对禁止加仓摊平**：只有持仓浮盈且量价二次共振确认时才允许按条件加仓。
5. **严禁车轱辘投顾套话**：禁止“长期向好但短期承压”等废话，只给量化点位与确定性盈亏比。

## 二、 极简实操指导手册
### 表1：【空仓建仓篇】
* 阶段一（40%底仓）：标的回踩至关键支撑位且分时止跌时介入底仓；
* 阶段二（30%确认仓）：放量突破日内高点或确认站稳均价线后加仓确认；
* 阶段三（30%备用现金）：严格保留现金机动仓位，防范突发性盘面退潮。

### 表2：【在手持仓篇】
* 继续持有：价格运行于均价线上方，量价结构健康；
* 严格条件加仓：持仓浮盈且突破关键阻力位，顺势追加；
* 冲高减仓50%：触及阶段目标阻力位，减半锁盈推保本；
* 获利清仓：出现顶背离或跌破跟踪止盈线，落袋为安；
* 破位硬止损：跌破止损保护底线，无条件离场，杜绝心存侥幸。
