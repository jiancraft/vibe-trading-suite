# 加密合约量化实盘执行协议 (Suite B Blueprint v2.0)

## 一、 核心架构原则
1. **强制逐仓隔离 (isolated)**：所有币种独立水密隔舱，单笔名义货值严格锁定，总保证金占用严格受控。
2. **显式锁死杠杆**：
   - 低波基石组 (BTC / ETH)：显式锁定逐仓杠杆，紧止损（-0.45%），初始止盈（+0.82%）；
   - 高波先锋组 (Meme / Altcoins)：锁定较低杠杆（如 20x），ATR防插针止损（-1.75%），目标止盈（+4.36%）。
3. **资金费率避震窗**：UTC 00:00 / 08:00 / 16:00 前后 3 分钟禁止新开仓，规避费率结算瞬时滑点。
4. **盘口价差保护锁**：盘口 Bid/Ask 价差超过阈值（主流 >0.05%，高波 >0.08%）时立即避让开仓。

## 二、 三阶动态出场体系 (40% / 30% / 30%)
* **TP1 (+1.5%)**：触及 TP1 平仓 40%，同时将剩余仓位止损推升至开仓保本价（BE）；
* **TP2 (+3.0%)**：触及 TP2 再平仓 30%，锁定确定性收益；
* **Trailing 尾仓 (30%)**：剩余 30% 尾仓启动移动追踪（回撤 1.2% 触发清仓），博取趋势超额利润。

## 三、 硬熔断纪律
* 日度最大亏损达到阈值时触发当日熔断，强制休克停止开新仓；
* 连续遭遇止损触及上限（如连续3笔）时触发 24 小时交易冻结。
